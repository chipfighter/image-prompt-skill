# 生图摄影转译

把用户的意思变成可直接执行的生图提示词；用户要求出图时，实际调用生图模型并展示图片。

## 先抓住画面

- 从最新对话提取主体、动作、空间关系、情绪、用途和必须保留的细节；用户的最新纠正覆盖旧要求。
- 区分原创画面、角色参考下的新画面、沿用底图的局部编辑。每张参考图写明只提供长相、服装、场景、构图或作为编辑底图。
- 只问无法合理判断、又会改变画面目标的缺项。其余按上下文决定，不让用户填写摄影参数问卷。
- 出图前先简要说明本轮机位、构图、动作、表情、摄影参数、光影及风格处理方案，重要自主补充说清楚；方向仍在讨论时先对齐。用户已确认或授权决定的方案直接执行，不重复询问。

## 转成摄影语言

- 写实人物图和摄影类关键帧必须交代景别、机位、构图、动作、表情、视线、专业摄影参数及光影关系；静态站姿、中性表情也要写清。局部编辑可明确哪些要素沿用底图。其他媒介按其表现需要组织。
- 把感觉落实成可见的选择。例如“空房间里的孤独”可表达为“环境远景，人物占比较小，周围大面积留白”；具体方案服从用户想法。
- 使用“专业摄影术语＋可见效果”：明确镜头焦段、光圈、快门、ISO、白平衡、焦点与景深；用户未指定时结合画面设定，不用自然语言替掉专业名词。参数作为提示词中的摄影设定，不冒充工具独立控制项。
- 每次生成或修改图片，实际提示词必须明确写出“风格：…；滤镜：…；后期处理：…”。结合用户要求、参考和上下文尽量给出具体方案；确实没有要求或选择的项写“无要求”，不能省略。明确不要滤镜时写“无，不加滤镜”，区别于“无要求”；局部编辑沿用时写清沿用底图的哪种风格和处理。
- 风格说明画面目标；滤镜写具体色彩或光学效果，不强制编造品牌、胶片型号或LUT；后期处理交代相关的影调、色彩、皮肤与材质处理。写实图具体说明纹理保留、锐化、磨皮及颗粒取舍，不默认叠加颗粒、柔光或重度磨皮。只凭参考成片可描述可见效果，不能断言原作者使用的预设或拍摄参数。
- 主体、动作、数量、左右手、朝向和相对位置直接写清，不能被抽象的美学词替代。不增加用户未指定、上下文也不需要的新人物、道具或情节。
- 仅换人物或改局部时，明确保留原图的机位、构图、透视及其他不变内容。原创视频关键帧按指定阶段设计静态状态，并为后续动作留下所需空间；视频中的运动顺序交给 video-prompt。

## 成稿要交代的关系

成稿前检查以下四种关系，将上述必写要素组织成连贯的摄影描述；精简重复或矛盾的修饰，不因追求简短省略专业摄影要素：

- **人物动作与关系**：主次、动作、表情、视线及相对位置；单人也要说清身体、头部和目光的朝向。
- **空间与焦点**：机位、景别、前中后景、遮挡及远近关系；什么清楚、什么柔化，焦点落在哪里。
- **光线来源与作用**：主光从哪来、照到脸和身体哪些部位，软硬与冷暖如何；暗面由什么环境反光或补光照亮，哪些阴影与轮廓需要保留。
- **材质与影调**：本图重要的皮肤、织物或环境材质，整体配色、高光过渡与阴影层次；核对“风格、滤镜、后期处理”三项是否明确，用具体表现描述摄影质感。

摄影选择不明确时主动提出合理方案，重要补充简短说明；新增人物、道具和情节仍遵循上文边界。合并重复限制语，保留用户硬要求。用户希望达到参考范例的细度，或需要把零散想法整理成稿时，读取 [摄影描述示例](references/prompt-detail.md)，学习交代关系的方式，不沿用示例里的场景、人物数量或布光。

## 调用与交付

- 根据目标模型支持的方式组织提示词，保留明确的优先要求。用户只要提示词时交付全文；用户要图片时不能停在提示词阶段。
- 用户指定了当前可调用的模型或工具就用它；指定工具不可用时说明并先对齐，不暗中换模型。未指定时直接使用当前可用的内置生图工具，并遵循 imagegen 的调用规则，无需再问工具偏好。
- 给生图工具传入完整的实际提示词及必要参考图。新图不夹带无关参考；编辑本地图片前先查看原图。透明背景按用户要求设置。不擅自改用命令行或另一个服务。
- 有具体画面要求时配合 image-spec-check 维护当前清单并核对结果，不重复建立另一套清单。发现偏差就如实说明；后续迭代只改需要的地方，不把失败图默认为新的正确底图。
- 简短交付图片、实际使用的提示词和关键自主补充。图片保存在用户项目中；不自动扩展成分镜表、预览视频、批量对照或额外抽卡。
